Waiki Argentine Tax Settlements for Odoo 19 Community
=====================================================

Argentine serializers preserve the supplied legacy layouts. The Odoo 19 adapter
reads each native payment withholding separately: certificate, base and tax amount.
Configure regimes and provincial metadata before exporting; acceptance by current
fiscal portals still needs validation with real filing scenarios.

An explicit setup wizard creates settlement journals with an accountant-selected
authority and counterpart account. Monthly inflation indices must be maintained;
missing months stop draft adjustment generation. Historical index data retain
noupdate to preserve accountant-maintained values. Review drafts before posting.
