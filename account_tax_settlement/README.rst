Waiki Tax Settlement for Odoo 19 Community
==========================================

Company-scoped draft tax settlements, native payment registration and audit CSV.
Configure a miscellaneous journal, authority partner, payable/receivable counterpart
and source taxes or tags. Only posted tax lines can be settled, once per line.
The audit CSV is not a fiscal filing. Community report domain closures are supported;
Enterprise report handlers and their interactive UI are not included.
